Updating this baseline is always a deliberate reviewed change. Run the Full
suite on `main`, download `nexus-benchmark-results-full`, and then run:

```powershell
./scripts/update-benchmark-baseline.ps1 `
  -InputPath ./target/nexus-bench/benchmark-results.json
```

The updater validates the Full aggregate and registered scenario set but never
runs benchmarks or downloads artifacts.
